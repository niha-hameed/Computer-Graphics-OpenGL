# Computer Graphics with OpenGL

A collection of computer graphics coursework and small programming exercises exploring 2D shapes, triangle arrangements, keyboard interaction, and geometric drawing.

## Contents

| Folder | Description |
| --- | --- |
| `Star-Shape` | Triangle-based star drawing exercise |
| `Keyboard-Interaction` | Keyboard input exercise |
| `Assignments` | Graphics assignment source files |
| `Lab-Exam` | Lab exercises including keyboard-controlled triangle colors |
| `Additional-Exercises` | Additional C# console exercise |

## Technologies
- C++ and OpenGL / GLUT
- C# / .NET for an additional exercise

## Running the examples
Install a C++ compiler and GLUT/freeglut with OpenGL development libraries. Compile each independent `.cpp` example separately because some files define their own `main()`.

## Notes
These are educational exercises, not one integrated application. Compilation and runtime behavior have not been verified. Coursework may include collaborative contributions; credit belongs to original contributors.
